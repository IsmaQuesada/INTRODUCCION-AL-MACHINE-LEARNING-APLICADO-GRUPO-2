# Machine Learning con scikit-learn — Notebooks de clase

Colección didáctica de notebooks de Jupyter en español sobre aprendizaje automático clásico. Cada notebook desarrolla un tema paso a paso, con ejemplos prácticos, visualizaciones y evaluación de modelos, todo implementado con scikit-learn (más pandas, numpy, matplotlib y seaborn).

## Contenido

| Directorio | Notebook | Tema |
|---|---|---|
| `Mi Primer ML/` | `Mi_Primer_ML.ipynb` | Introducción a Machine Learning: acceso a datos, partición entrenamiento/validación/prueba, preprocesamiento, pipelines y métricas de desempeño |
| `Arbol y Bosque/` | `ArbolBosque.ipynb` | Árboles de decisión y Random Forest (bosques aleatorios) |
| `KNN/` | `kNN.ipynb` | k-Vecinos más cercanos (kNN), con Grid Search y Randomized Search |
| `Bayes Ingenuo/` | `BayesIngenuo.ipynb` | Naive Bayes gaussiano |
| `SVM/` | `SVM.ipynb` | Máquina de Vector Soporte: hiperplano separador, kernels lineal y RBF, parámetros C y gamma |
| `RLyRegularizacion/` | `RLogistica.ipynb` | Regresión logística (caso aprobación de tarjetas de crédito), fine tuning y regularización |
| `RLyRegularizacion/` | `Regularizacion.ipynb` | Métodos de regularización |
| `RN/` | `RedNeuronalArtificial.ipynb` | Red neuronal artificial: perceptrón multicapa (MLPRegressor), curvas de aprendizaje e importancia de variables |
| `CurvaROC/` | `CurvaROC.ipynb` | Curva ROC y métrica AUC, ajuste del umbral y comparación de modelos |
| `Curvas de aprendizaje/` | `CurvaAprendizajeML.ipynb` | Sesgo alto vs. varianza alta y curvas de aprendizaje |
| `Clases no balanceadas/` | `Clases_No_Balanceadas.ipynb` | Problema del desbalance de clases, métricas (precision, recall, F1, G-mean) y técnicas de balanceo (submuestreo/sobremuestreo) |

Los notebooks están pensados para abrirse en Jupyter y ejecutar las celdas en orden.
